# 投資動向ダッシュボード 設計書

- 日付: 2026-08-15
- ステータス: 承認済み

## 背景・目的

株価指数、個別株、為替の動向をスマホでも見やすく確認できるウェブページを作る。投資の基礎用語が分からなくても使えるよう、用語解説も提供する。

## スコープ

対象:
- 株価指数(日経平均、S&P500 など)
- 個別株式(日本株・米国株など、ティッカーで指定)
- 為替(USD/JPY など)

対象外(初期スコープでは実装しない):
- 投資信託・ETF、暗号資産
- 自動ポーリングによるリアルタイム更新
- 複数ユーザー間でのウォッチリスト共有・サーバー側永続化
- ログイン・認証機能

## アーキテクチャ

```
[ブラウザ]
   │  静的ファイルを配信
   ▼
[GitHub Pages]  (index.html / glossary.html / css / js)
   │  fetch (JSON)
   ▼
[Cloudflare Workers]  (CORSプロキシ + レスポンス整形 + 簡易キャッシュ)
   │
   ▼
[Yahoo Finance 非公式API]  (quote / chart / search エンドポイント)
```

- フロントエンドはビルド不要の Vanilla HTML/CSS/JS。フレームワークは使わず、GitHub Pages にそのまま配置する。
- Yahoo Finance の非公式エンドポイントは CORS ヘッダーを返さないため、ブラウザから直接呼び出せない。Cloudflare Workers を単純な中継プロキシとして挟み、CORS ヘッダーを付与する。
- Workers は無料枠(1日10万リクエスト)で個人利用には十分。

## 画面構成

### `index.html` (ダッシュボード)

- デフォルトのウォッチリスト(日経平均・S&P500・USD/JPY など)をカード形式で表示
- 各カードの内容:
  - 銘柄名・ティッカー
  - 現在値
  - 前日比(値・%、上昇は緑/下落は赤)
  - 簡易ラインチャート(過去3ヶ月程度の日足終値、SVGで自前実装。外部チャートライブラリは使わない)
  - 主要な数値(現在値・前日比など)には `?` アイコンでツールチップ表示し、用語集の該当項目にリンク
- 検索欄からティッカーを検索して追加できる(Yahoo Finance の search エンドポイント経由)
- 追加したウォッチリストは `localStorage` に保存する(サーバー側DBは持たない、個人利用前提)
- カードには削除ボタンを設置し、ウォッチリストから外せる
- 手動更新ボタンを画面上部に設置。自動ポーリングは行わない
- レスポンシブCSS(Flexbox/Grid)。スマホ幅(〜480px)ではカードを1列に、タブレット・PC幅では複数列に

### `glossary.html` (用語集)

- カテゴリ分け(指数・個別株・為替・共通指標など)して基礎用語を一覧表示
- 例: 株価指数、PER、出来高、為替レート、前日比、ティッカーシンボル など
- ダッシュボードのツールチップから対応する見出しへアンカーリンクできるようにする
- ダッシュボードとの間に相互ナビゲーションリンクを設置

## データ取得・API設計

Cloudflare Workers で以下のエンドポイントを用意する:

- `GET /api/quote?symbols=^N225,USDJPY=X,AAPL` — 現在値・前日比をまとめて取得
- `GET /api/chart?symbol=^N225&range=3mo&interval=1d` — 指定銘柄の日足終値推移を取得
- `GET /api/search?q=toyota` — ティッカー検索

Workers 側の役割:
- Yahoo Finance 非公式APIへのリクエスト中継
- レスポンスJSONを、フロントが必要とする最小限の形に整形(不要フィールドを削る)
- CORSヘッダー付与
- 上流障害時は該当銘柄のみエラーを返す(他の銘柄の取得は継続)

## エラーハンドリング

- 個別銘柄のAPI取得失敗: 該当カードに「取得できませんでした」+ 再試行ボタンを表示。他のカードの表示には影響しない
- 検索結果が0件、または存在しないティッカー: 検索欄下にメッセージ表示
- Workers 自体が応答しない場合: ページ全体に軽いエラーバナーを表示し、手動更新ボタンでの再試行を促す

## テスト方針

- Cloudflare Workers 側: quote/chart/search のレスポンス整形ロジックに対する単体テスト(上流APIのレスポンスをモックして、整形後のJSON構造を検証)
- フロントエンド: 自動テストは設けず、ブラウザでの手動確認を中心に行う(PC幅・スマホ幅の両方、正常系・API失敗時の表示、ウォッチリスト追加/削除、localStorage永続化)

## デプロイ

- フロントエンド: GitHub Pages。このリポジトリの `origin` (`github.com/emperorpenguinA/20260815`) の `main` ブランチ(または `gh-pages`)から配信
- プロキシ: Cloudflare Workers。実際のデプロイ(Cloudflareアカウント作成・`wrangler` によるデプロイ)はユーザー側の認証が必要なため、実装フェーズで手順書(`wrangler.toml` の内容、`wrangler login`・`wrangler deploy` の実行手順)を用意する。実行自体はユーザーが行う

## 未確定事項・今後の検討

- ウォッチリストの初期銘柄セット(日経平均・S&P500・USD/JPY 以外に何を含めるか)は実装時に相談して決める
- Yahoo Finance 非公式APIは仕様変更・レート制限のリスクがある。将来的に安定した有料/公式APIへの切り替えが必要になる可能性がある
